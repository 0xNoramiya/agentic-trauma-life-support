# Benchmarks

MI300X benchmark numbers for ATLS, generated by `scripts/run_benchmarks.py`.

Read these as relative numbers, not absolute production performance: the placeholder X-ray used by the benchmark is a 1024×1024 grey JPEG, not a real radiograph. Wire in a real image (or point the script at one locally) for representative TTFT.

Each section below corresponds to one scenario. The benchmark script overwrites the section between its delimiter comments on each run, so you can re-run individual scenarios without losing the others.
