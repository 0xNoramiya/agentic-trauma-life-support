# ROCm + vLLM feedback — ATLS hackathon

A running list of issues, friction, and nice-to-haves from running Qwen2.5-VL-72B in BF16 on a single MI300X via the `rocm/vllm-dev:nightly` container. Each entry follows the same template so the AMD team can triage them quickly.

## Format

For each finding:

- **Severity:** blocker / friction / nit
- **Title:** one-line summary
- **Description:** a paragraph
- **Repro steps:** numbered, copy-pasteable
- **Suggested fix:** one or two sentences
- **Logs / artifacts:** links or pasted excerpts
