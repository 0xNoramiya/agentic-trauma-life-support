ATLS — Inline image prompts for the technical blog post
docs/BLOG_POST.md, ~2,400 words. Six images, each anchoring a major section.

How to use:
- Paste each prompt into ChatGPT (any image-capable model)
- All six share the same clinical-editorial visual identity as the
  cover_prompts.txt set, so the blog reads as one piece with the
  social-media covers
- Aspect ratio noted per prompt (most are 16:9; the timeline figure is
  21:9 because the bar of silence wants room)
- Where each image goes in BLOG_POST.md is noted at the start of each block

Palette (every prompt enforces this):
  warm paper canvas       #F8F7F4
  deep ink primary text   #1A1F2E
  sage green accent       #3A7A6E
  light grey hairline     #D9D6D0
  terracotta (used once)  #B8463A

Anti-pattern footer (append if needed):
  "Strict no: glowing brains, neural-network mesh, holographic doctors,
   stock-photo physicians, futuristic UI mockups, flat-design illustration,
   gradient backgrounds. The aesthetic is editorial print, not SaaS marketing."
