ATLS — Cover image prompts for LinkedIn + Twitter
Build-in-Public series, AMD Developer Hackathon (May 2026)

How to use:
- Open ChatGPT (any image-capable model — DALL-E / GPT-4 with images / Sora image)
- Find the prompt section you need below
- Select everything between the dashed lines (just the prompt body)
- Paste into ChatGPT
- All eight prompts share the same clinical-editorial visual language
  (warm paper #F8F7F4, deep ink #1A1F2E, sage accent #3A7A6E, single
  terracotta #B8463A only used once on the credibility-case cover)

The prompts are written so the eight covers read as a series — same canvas,
same typography family, same restraint. Sequence them in the order below
and they tell the same story across the two platforms.

Aspect ratio for every prompt: 16:9 (1920x1080).

If ChatGPT keeps adding glowing brains, neural-network meshes, or stock-photo
doctors, append this sentence to any prompt:
  "Strict no: glowing brains, neural-network mesh patterns, holographic
   doctors, futuristic UI mockups, flat-design illustrations. The aesthetic
   is editorial print, not SaaS marketing."
